# 오픈소스 고지문 작성

명령은 저장소 루트에서 실행합니다.

```sh
python3 .claude/skills/blackduck-notice/scripts/notice.py --output <경로.html> [--project 프로젝트] [--version 버전] [--force]
```

Python 3.9 이상이 필요하고, 표준 라이브러리만 사용합니다. Windows에서 `python3`가 없으면 `python`이나 `py -3`으로 실행합니다. 서버 접속 코드와 `config.properties`는 `blackduck` 스킬의 것을 쓰므로 두 스킬은 `.claude/skills/` 아래에 함께 있어야 합니다. 토큰은 출력하거나 명령줄에 넣거나 답변에 포함하지 않습니다.

프로젝트나 버전을 지정하지 않았고 후보가 여러 개이면 스크립트가 오류와 함께 후보 목록을 출력합니다. 임의로 고르지 말고 사용자에게 묻습니다.

`scripts/notice.py`는 `templates/notice-template.html`에 BOM 데이터를 채워 HTML 파일을 만듭니다. 고지문의 문구와 양식은 이 템플릿에만 있습니다. 문구나 양식을 바꾸려면 템플릿을 고치고, 스크립트나 생성된 HTML을 고치지 않습니다.

템플릿에는 `COMPONENT`와 `LICENSE` 반복 구간이 하나씩 있어야 합니다. 구간은 `<!-- BEGIN 이름 -->`, `<!-- END 이름 -->`으로 표시하며 항목 수만큼 반복됩니다.

| 구간 | 자리표시자 |
|---|---|
| `COMPONENT` | `{{label}}`(컴포넌트와 버전), `{{license}}`, `{{copyright}}`, `{{url}}` |
| `LICENSE` | `{{name}}`, `{{components}}`(이 라이선스를 쓰는 컴포넌트 목록), `{{text}}`(전문) |

값이 비어 있고 자리표시자만 있는 줄은 줄째 빠집니다. 값은 HTML 이스케이프되어 들어갑니다. 구간이나 자리표시자가 틀리면 스크립트가 오류를 냅니다.

실행 전에 다음을 확인합니다.

- **대상 버전:** 고지문은 실제 배포물의 목록이어야 합니다. `blackduck` 스킬의 `status`(Code locations)와 `components`로 배포물을 스캔한 버전인지 확인합니다. 가상환경이나 개발 도구까지 스캔한 버전이면 배포되지 않는 항목이 포함되므로 사용자에게 알립니다. 어떤 버전인지 모르면 묻습니다.
- **출력 경로:** 파일이 이미 있으면 내용을 확인한 뒤 사용자가 동의한 경우에만 `--force`를 씁니다.

실행 후 스크립트가 출력하는 `Review before release` 항목을 빠짐없이 사용자에게 전합니다.

| 항목 | 의미 | 안내할 내용 |
|---|---|---|
| `no confirmed copyright` | 서버에 확정된 저작권 정보가 없어 저작권 줄이 빠짐 | 패키지의 LICENSE, NOTICE 파일에서 확인 |
| `no homepage` | 홈페이지 정보가 없어 URL 줄이 빠짐 | 필요하면 Black Duck에서 보완 |
| `license unidentified or without text` | 라이선스가 식별되지 않았거나 전문이 없어 라이선스 절에 나오지 않음 | 실제 라이선스를 확인해 Black Duck에서 지정 |
| `copyright statements omitted` | 최신 한 줄만 남기고 뺀 저작권 줄 수 | 아래 "저작권은 한 줄만 표시합니다" 참고 |
| `same latest year` | 같은 연도의 다른 저작권 줄이 있어 알파벳순 첫 줄을 고른 컴포넌트 수 | 다른 저작권자가 빠졌을 수 있음 |
| `shown copyright has no year` | 연도가 있는 줄이 없어 연도 없는 줄을 표시 | 표시된 줄이 맞는지 확인 |
| `shown copyright looks like code or prose` | 표시된 줄이 코드나 문장으로 보임. 정상 줄이 있으면 그쪽을 우선하므로 다른 후보가 없는 경우임 | 검토 후 Black Duck에서 수정 |
| `non-English characters` | 제3자 이름, 저작권, 라이선스 전문에 있는 비영어 문자. 원문이므로 번역하지 않음 | 그대로 둘지 확인 |
| `not marked reviewed` | 서버에서 검토 완료되지 않은 컴포넌트 수 | BOM 검토 절차 확인 |
| `copyleft or unknown license families` | 고지 외의 의무가 따를 수 있는 라이선스 | 아래 참고 |

고지문을 다룰 때는 다음을 지킵니다.

- **저작권은 한 줄만 표시합니다.** 컴포넌트 버전별로 저작권 줄의 연도 중 가장 큰 값을 기준으로 한 줄을 고릅니다. 패키지 안에 포함된 제3자 코드의 표기가 뽑힐 수 있고(`transformers`에 NVIDIA), MIT, BSD, Apache 등은 저작권 표시를 유지하도록 요구하므로, 나머지 저작권자가 빠진다는 점을 고지문을 만들 때마다 알립니다.
- **라이선스 전문은 서버의 표준 전문을 씁니다.** 라이선스마다 전문을 한 번만 싣습니다. 컴포넌트별로 저작권자가 채워진 전문은 쓰지 않습니다.
- **빠진 값을 추측해서 채우지 않습니다.** 저작권자, 라이선스, URL은 서버 값만 씁니다. 양식에 맞추려고 값을 지어내지 말고, 해당 줄을 뺀 뒤 검토 항목으로 알립니다. 생성된 HTML을 손으로 고치기보다 Black Duck에서 수정한 뒤 다시 생성하도록 안내합니다.
- **저작권 줄이 잘렸을 수 있습니다.** Black Duck의 저작권 값은 비ASCII 문자에서 끊긴 경우가 있습니다(`Alex Grönholm`이 `Alex Gr`로 저장됨). 스크립트로는 모두 찾아낼 수 없으므로 이 점을 사용자에게 알립니다.
- **고지문만으로 의무가 끝났다고 말하지 않습니다.** GPL, LGPL, AGPL, MPL 등은 소스 코드 제공 같은 추가 의무가 따를 수 있고, 양식에는 소스 코드 제공 문구가 없습니다. 이런 항목이 있으면 법무나 오픈소스 담당 부서의 검토를 안내합니다.
- **외부에 올리지 않습니다.** 파일은 로컬에만 만들고, 게시 여부는 사용자가 정합니다.

사용자의 언어로 답합니다. 스크립트가 HTTP 401 오류를 내면 토큰을 새로 발급해 `blackduck` 스킬의 `config.properties`에 저장합니다.
